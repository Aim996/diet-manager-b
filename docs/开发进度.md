## 发现问题

| 问题 | 影响 | 当前处理 |
|---|---|---|
| README 与 START-HERE 状态冲突 | 新智能体无法判断 B-only 和是否可安装 | 本轮统一为 B-only、开发交接、非 PRODUCT |
| Node 24.14.0 不满足 OpenClaw 2026.7.1 | 旧命令在干净环境直接失败 | 交接和 package engine 收紧为 `>=24.15.0 <25` |
| pnpm 11 默认拒绝依赖构建脚本 | `pnpm install --frozen-lockfile` 首次失败 | 仓库内固定五项 allowBuilds，禁止 `--all` |
| 私有 GitHub 需要授权 | 专用 OpenClaw 可能无法直接 clone | 02 环境首先验证；缺权限明确报 `GITHUB_AUTH_REQUIRED`，不泄漏凭据 |
| 当前插件无真实业务实现 | 加载成功可能被误解为可记录 | 文档、清单、测试和行为冒烟共同锁定 `committed=false` |
| 当前没有开源许可证 | 即使代码可见也不构成合法开源授权 | 保持私有；公开前由用户选择许可证并重跑历史/密钥复核 |
