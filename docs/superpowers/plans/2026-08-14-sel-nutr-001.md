> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 0.3 营养来源、计算、Profile/Snapshot、字段级公开证据、网络恢复追加补全和只读 Doctor，同时保留八个公开 action 和现有 B 路线事务协议。

**Architecture:** 先用现有 `command_envelopes/idempotency_records` 建立受 HMAC 保护的 v6 营养解析占位，以 base digest 单飞动态来源解析；再把首次营养和后续 supplement 都接入 FactCommit → EffectBundle → EnvelopeFinalize。来源严格按共享 registry 八层执行，运行入口改为异步，SQLite migration 保持 v1 不变。

**Tech Stack:** TypeScript ESM、Node.js 24.15、OpenClaw 2026.7.1、TypeBox、Vitest 2、Node `DatabaseSync` SQLite、PowerShell/Node 共享 Schema validators。
