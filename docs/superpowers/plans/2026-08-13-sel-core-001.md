# SEL-CORE-001 Core Command Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the deterministic current-user meal/water command slice, persist explicit meal and WaterEvent facts through the existing B transaction authority, and replace the public OpenClaw foundation outcome with truthful core outcomes.

**Architecture:** Keep text interpretation in small pure modules, keep the existing structured domain service authoritative for writes, and add one application adapter between parser and service. Extend the existing generic event/outbox/finalizer path for WaterEvent without a schema migration; leave inventory, external nutrition, complete goal progress, Issue UX, installation, and remote acceptance to their ordered successor tasks.

**Tech Stack:** Node.js 24.15.0, TypeScript, Vitest, TypeBox, built-in `node:sqlite`, OpenClaw tool-plugin SDK.
