# SH-MODEL-003 Issue, Correction, and Mixed Result Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze a shared JSON Schema v1 for Issue, append-only correction, three-stage transaction/outbox state, ordered mixed results, and terminal ReceiptData while proving that failed fact writes create zero dietary business objects.

**Architecture:** One route-neutral JSON Schema owns the Issue/Correction/transaction/mixed model and references existing SH-MODEL-001/002 schema identities where those models are authoritative. A fixed full-object fixture corpus drives a dependency-free Windows PowerShell 5.1 validator that checks exact shape plus cross-object state-machine, idempotency, ordering, and failure-atomicity invariants.

**Tech Stack:** JSON Schema 2020-12, JSON, Markdown, Windows PowerShell 5.1, SHA-256, optional independent Ajv 8 review.

## Global Constraints

- Route B is the only future writer; create no A/C production model, route score, or duplicated business implementation.
- Create no SQLite table, migration, repository, outbox worker, business record, runtime adapter, renderer, OpenClaw/MCP handler, or installable Skill.
- Failed FactCommit may write only a separate redacted technical log outside the business schema and must create zero fact, inventory, nutrition, Issue, outbox, progress, receipt, or terminal-idempotency business objects.
- EffectBundle failure keeps the committed fact and retries only unfinished effects; EnvelopeFinalize failure keeps facts/effects pending and creates no success receipt or progress.
- Correction is append-only and supports exactly the 13 frozen operations and 14 frozen fields.
- Issue uses exactly four statuses; outbox uses exactly five statuses; command results use exactly five statuses.
- Do not read, hash, track, edit, or execute the five protected lease files.
- Follow TDD: observe the missing-schema RED before adding schema or fixtures, and observe every semantic mutation fail before accepting the final candidate.
