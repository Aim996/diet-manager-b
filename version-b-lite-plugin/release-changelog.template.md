0.1.1 在 0.1.0 主链基础上补齐完整 0.1 业务并形成可发布闭环：

- **撤销**：餐食/采购事实的 void_event 撤销，含并发与故障门。

- **安装与灾备**：事务式安装/升级/回滚/卸载，AES-256-GCM + scrypt 便携加密备份，TTY 口令交互式灾备 CLI。
- **验收**：真实 OpenClaw 网关 + USDA 数据源的产品验收场景、执行器与证据结构，绑定不可变候选字节。
