# 变更记录

## 0.2.0（源码提交 `9292579e11513738784a0d061fee20cd07e337b3`）

0.2.0 在 0.1.1 可发布闭环之上引入个人画像、六项目标与每日进度条，并补齐撤销记录的恢复能力，契约推进至 contract-v3：

- **个人画像（DEC-030 set_profile）**：自然语言录入性别、身高、体重、年龄与目标状态，校验后落库并派生六项每日目标（热量、蛋白质、脂肪、碳水、白水、采购项数）。
- **六项目标（DEC-030 set_goal）**：目标子集覆盖与清除，逐项持久化到 goal_versions，保留权威来源。
- **进度条（DEC-030 query_daily_summary）**：每日摘要返回六域目标进度，真值百分比上限 100%，未配置目标时如实缺省。
- **恢复记录（DEC-031 restore_record）**：把已撤销（void）的餐食/采购事实恢复为活跃，营养与进度随更正链回到原值；仍活跃的记录如实拒绝。
- **契约 v3**：动作新增 set_profile / set_goal / restore_record，共 11 个动作；业务事实 schema 保持 domain/v2 不变。
- **承接 0.1.1**：撤销、纠正、多商品采购、查询回执、事务式安装与加密灾备、真实网关/USDA 验收基线全部保留。
